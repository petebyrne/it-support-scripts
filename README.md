# IT Support Scripts

A small collection of beginner-friendly PowerShell scripts created as part of my development toward IT Support and Service Desk roles.

The scripts are designed to practise common support concepts such as gathering system information, checking disk space, reviewing network settings and documenting troubleshooting output.

This project is not intended to replace enterprise tooling. It is a learning project focused on building familiarity with PowerShell, Windows support tasks and structured technical troubleshooting.

## Scripts

### disk-space-check.ps1

Checks available disk space on local drives and displays used/free space.

### network-diagnostics.ps1

Displays basic network information including IP address, DNS servers and default gateway.

### system-info-report.ps1

Collects basic system information such as computer name, operating system, uptime and logged-in user.

### list-local-users.ps1

Lists local user accounts on the Windows device.

### password-generator.ps1

Generates a random password for lab/testing use.

## Skills Demonstrated

- Basic PowerShell scripting
- Windows support fundamentals
- System information gathering
- Network troubleshooting
- User account awareness
- Technical documentation
- Practical IT support learning

## Notes

These scripts are intended for learning and lab use only. In a real business environment, scripts should be reviewed, tested and approved before use.
